# Archive: Urban Pulse (alte Veinue-Website)

Vollständige Kopie der Landing vor „Find your people.“ — City-Skyline, Venues/Deals, Safe Nights, JPG-Hintergründe, SVG/Canvas-Look.

## Wiederherstellen (empfohlen)

```bash
git checkout archive/urban-pulse
```

Branch `archive/urban-pulse` ist ein Snapshot von `origin/main` zum Archiv-Zeitpunkt.

## Oder aus diesem Ordner

Inhalt hier ist `git archive` von dem Stand. `src/`, `public/`, `index.html` und Assets (`src/assets/bg-*.jpg`) zurück nach Repo-Root kopieren, `npm i && npm run dev`.
